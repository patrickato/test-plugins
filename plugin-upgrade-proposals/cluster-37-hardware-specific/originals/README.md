# Originals preserved before merging into BluetoothReconNG

These are exact, unmodified copies of the two source plugins that were
merged together into `bluetooth-recon-suite` (`BluetoothReconNG`) in
patrickato/plugins-wip, kept here specifically so the originals are not
lost if the merged plugin needs to be abandoned/reverted for any reason.

- `blemon_plugin.py` - copied verbatim from `itsdarklikehell/pwnagotchi-plugins/blemon_plugin.py`
- `blemon_plugin.config.original.toml` - its real upstream config, copied verbatim from `itsdarklikehell/pwnagotchi-plugins/configs/blemon_plugin.toml`
- `bluetoothsniffer.py` - copied verbatim from `itsdarklikehell/pwnagotchi-plugins/bluetoothsniffer.py`
- `bluetoothsniffer.config.original.toml` - its real upstream config, copied verbatim from `itsdarklikehell/pwnagotchi-plugins/configs/bluetoothsniffer.toml`

See `../NOTES.md` for the full writeup of what was wrong with each original
and what BluetoothReconNG does differently.
